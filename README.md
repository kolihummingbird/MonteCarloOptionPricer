# Monte Carlo Option Pricer with Black–Scholes Benchmark (C++)
## 1. Overview
A small C++ project focused on Monte Carlo pricing of European call options under the Black–Scholes framework.

The project simulates stock price paths using Geometric Brownian Motion (GBM), estimates option prices through Monte Carlo methods, and compares the numerical results against the analytical Black–Scholes solution.

The goal of the project is (mainly) educational and technical, in addition:

* practicing stochastic simulations and numerical methods,
* improving C++ knowledge,
* exploring the mathematical foundations of quantitative finance.

The repository is still under active development and additional features, optimizations, and documentation are planned.
